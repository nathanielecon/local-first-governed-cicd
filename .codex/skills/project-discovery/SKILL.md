# Discover the Project

1. Read `PROJECT.md`, `PLAN.md`, `STATUS.md`, and relevant decisions.
2. Separate observable outcomes from requested implementation details.
3. Record users, constraints, risks, exclusions, and unavailable credentials.
4. Identify claims requiring evidence and explicitly prohibit unsupported production or cloud claims.
5. Propose updates to `PROJECT.md`; do not begin implementation.
6. Ask the orchestrator to record the next gate through the project CLI. Do not edit authoritative state blocks directly.

Stop for human direction when the outcome or a high-impact scope boundary remains ambiguous.
